# 测试知识库

团队知识库，使用 `kb` 命令行工具管理。

## 快速开始

```bash
# 添加知识条目
kb add "标题" --project 项目名 --tags 标签1,标签2

# 搜索
kb search "关键词"

# 查看所有条目
kb list
```

## 命令说明

- `kb init` - 初始化知识库
- `kb add` - 添加知识条目
- `kb search` - 搜索知识条目
- `kb link` - 管理相关链接
- `kb review` - 内容复审管理
- `kb export` - 导出知识库
- `kb shortcut` - 管理快捷命令
